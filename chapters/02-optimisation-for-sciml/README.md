# Chapter 2: Introduction to optimisation methods for training SciML models

**Authors:** Alena Kopanicakova and Elisa Riccietti

This folder accompanies the chapter on optimisation methods, stochastic
training, loss balancing, embeddings, and sampling strategies for SciML.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

## Execution
Each notebook in this folder is self-contained and can be executed independently. There is no required execution order or dependency between notebooks.

After completing the setup, open any notebook in JupyterLab and run its cells sequentially from top to bottom.
